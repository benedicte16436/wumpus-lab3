# Лабораторная работа №3 — «Мир Вампуса» (Java)

Консольная реализация интеллектуального агента на основе базы знаний.

## Требования
- Java 17+ (используются `record` и switch expression).
- Компиляция и запуск из корня проекта:

```bash
javac -d out src/main/java/wumpus/*.java
java -cp out wumpus.Main
```

При запуске можно указать размер N (N >= 4) и seed случайной генерации. Seed позволяет повторить ту же конфигурацию среды.

## Структура
- `World` — среда: скрытая карта, ямы, Вампус, золото, датчики и действия охотника.
- `Perception` — значения пяти датчиков: Stench, Breeze, Glitter, Bump, Scream.
- `KnowledgeBase` — долговременная память наблюдений и выводов о безопасных клетках и кандидатах опасностей.
- `HunterAgent` — выбор действий, логические выводы, поиск маршрута BFS только по известным безопасным клеткам.
- `Main` — запуск симуляции и печать журнала.

## Принцип работы
1. Среда случайно распределяет Вампуса, золото и ямы. Вероятность ямы в каждой комнате, кроме стартовой, равна 0,2.
2. Агент стартует в (1,1), направлен на восток и получает только показания датчиков.
3. База знаний сохраняет восприятия. Отсутствие Breeze/Stench исключает опасность в соседних клетках; положительные Stench ограничивают множество возможных мест Вампуса.
4. BFS строит маршрут к не посещенной доказанно безопасной клетке.
5. При обнаружении Glitter агент забирает золото и пытается вернуться в (1,1), после чего выполняет Climb.
6. Стрела применяется только когда положение Вампуса определено однозначно и он находится на линии стрельбы.

В конце симуляции выводится скрытая карта для отладки и проверки преподавателем. Агент не использует ее при принятии решений.
